# Fix StationCombobox RTL layout

## Problem
The trigger button text alignment is wrong in Persian mode, and `rtl:flex-row-reverse` on dropdown items is reversing in the wrong direction due to how Tailwind's RTL variant interacts with the document's `dir="rtl"`.

## File
`/home/ali/tehran-metro-app/components/station-combobox.tsx`

## Changes

### 1. Trigger button (line 93)
Add `text-start` so placeholder aligns to the correct side per writing direction (right in RTL, left in LTR):
```
- className="flex w-full items-center gap-2 rounded-lg ... text-sm ..."
+ className="flex w-full items-center gap-2 rounded-lg ... text-sm text-start ..."
```

### 2. Dropdown station items (line 169)
Remove `rtl:flex-row-reverse` and use a conditional class instead. In RTL, `flex-direction: row` already flows right-to-left, which puts MapPin at start (right) and colors at end (left) — opposite of what we want. So swap to `flex-row-reverse` only in RTL:

```
- "flex rtl:flex-row-reverse w-full items-center gap-2.5 px-3 py-2 text-sm hover:bg-accent",
+ "flex w-full items-center gap-2.5 px-3 py-2 text-sm hover:bg-accent" + (isFa ? " flex-row-reverse" : ""),
```

Wait — actually `rtl:flex-row-reverse` in Tailwind means: when `[dir="rtl"]` is on a parent, apply `flex-direction: row-reverse`. The document already has `dir="rtl"` set via JS. So this SHOULD work.

Let me reconsider: the issue is that `rtl:flex-row-reverse` gives `row-reverse` in RTL. Normal RTL `flex-direction: row` flows right-to-left. `row-reverse` in RTL flows left-to-right. DOM order MapPin→text→colors becomes MapPin(left)→text→colors(right). That puts colors at the right (start) and MapPin at the left (end) — which IS what the user wants.

So the dropdown ordering may actually be correct. The real problem is likely just the trigger button text alignment.

### Revised plan — trigger button only

**Line 93**: Add `text-start` to the button className so text aligns to the writing-mode start:
```
className="flex w-full items-center gap-2 rounded-lg border border-input bg-background px-3 py-2.5 text-sm text-start transition-colors hover:bg-accent/50 focus:outline-none focus:ring-2 focus:ring-ring"
```

This ensures:
- English: text aligns left (start)
- Persian: text aligns right (start)
