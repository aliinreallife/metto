# Plan: Fix Cross-Line False Edges in Graph

## Root Cause Confirmed
`metro-data.ts` declares cross-line relations that create false edges:
- `Ayatollah Kashani` (L6) → `Allameh Jafari` (L4) — no shared line
- `Daneshgah-e Sharif` (L2) → `Shademan` (L4) — both on L2, so this one is valid

The graph repair in `graph.ts` links all declared relations without checking if stations share a line. This lets Dijkstra find "shortcuts" through non-existent cross-line connections.

## Fix
In `graph.ts`, add a line-sharing check to the `link()` function:

```typescript
const link = (a: string, b: string) => {
  if (a === b || !STATION_BY_ID.has(a) || !STATION_BY_ID.has(b)) return
  const sa = STATION_BY_ID.get(a)!
  const sb = STATION_BY_ID.get(b)!
  if (!sa.lines.some(l => sb.lines.includes(l))) return // skip cross-line
  adj.get(a)!.add(b)
  adj.get(b)!.add(a)
}
```

## Impact
- Aghdasiyeh → Allameh Jafari: L3 → L4 (1 transfer, correct)
- All other routes: no valid edges removed (only false cross-line edges blocked)
