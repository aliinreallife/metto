# Fix: Colored dots count should include start and end stations

## Problem
Currently the horizontal route spine in `SegmentCard` only shows dots for intermediate stations (`stations.slice(1, -1)`), and the displayed count shows `intermediates.length`. The user wants dots and counts to include the start and end stations too.

## Changes

### File: `components/route-panel.tsx`

1. **Horizontal route spine dots (lines 169-187)**: Change the dots to represent ALL stations (start + intermediates + end), not just intermediates. Replace `intermediates` with `stations` in the dot rendering logic.

2. **Expand button count (line 212)**: Change `{persianDigits(intermediates.length, lang)}` to `{persianDigits(stations.length, lang)}` so it shows total stations including start/end.

3. **Stat card stops count (line 38)**: Change `route.numStops` to `route.numStops + 1` so it shows total stations (start + intermediate hops + end).

### Specific code changes:

**Line 38** - Stat card:
```tsx
value={persianDigits(route.numStops + 1, lang)}
```

**Line 169-187** - Horizontal route spine dots:
Change `intermediates.length` checks and rendering to use `stations` array, showing dots for all stations.

**Line 212** - Expand button:
```tsx
{persianDigits(stations.length, lang)} {t.stops}
```
