# Fix: Mobile bottom tab bar position

## Problem
The mobile bottom nav bar is inside the flex flow of `AppNav`, so it renders after the content instead of being pinned to the viewport bottom.

## Fix
In `app/nav.tsx`, change the mobile bottom nav from inline flow to fixed positioning:

**Line 87** — change:
```tsx
<nav className="z-20 grid grid-cols-4 border-t border-border bg-card/90 backdrop-blur md:hidden">
```
to:
```tsx
<nav className="fixed bottom-0 inset-x-0 z-20 grid grid-cols-4 border-t border-border bg-card/90 backdrop-blur md:hidden">
```

Also need to add bottom padding to the page content so it doesn't get hidden behind the fixed nav. Add `pb-14 md:pb-0` to the children wrapper in `app/layout.tsx` line 190:

```tsx
<div className="relative min-h-0 flex-1 flex flex-col pb-14 md:pb-0">{children}</div>
```

## Files
- `app/nav.tsx:87` — add `fixed bottom-0 inset-x-0` to mobile nav
- `app/layout.tsx:190` — add `pb-14 md:pb-0` to children wrapper

## Verification
1. Build passes
2. Mobile: bottom tabs pinned to viewport bottom, content doesn't hide behind them
3. Desktop: no change (bottom nav is `md:hidden`)
