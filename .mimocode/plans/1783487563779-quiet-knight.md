# Full Performance Optimization Plan

## Priority 1: Critical — Schedule data (5.5 MB → lazy loaded)

`lib/schedule-data.ts` is 5.5 MB and bundled into every client page. Fix: load it on demand.

- Convert `schedule-data.ts` from static export to JSON file in `public/`
- Change `schedule-utils.ts` to `fetch()` the JSON lazily (only when departure times are needed)
- Cache in memory after first load
- Impact: -2 MB from initial bundle

## Priority 2: High — Loading states + Suspense fallbacks

- Add `loading.tsx` to `/`, `/stations`, `/nearby`, `/map`
- Add Suspense fallbacks in `page.tsx` and `map/page.tsx`
- Impact: eliminates blank flashes, shows instant loading UI

## Priority 3: High — Remove dead code

- Remove `@base-ui/react` from package.json (unused)
- Delete `lib/layout.ts` (comment-only dead file)
- Impact: smaller install, cleaner codebase

## Priority 4: Medium — Font optimization

- Remove Geist/Geist_Mono fonts (app is Farsi-first, these are Latin-only)
- Drop Vazirmatn weight 800 → 700
- Impact: ~80 KB font savings

## Priority 5: Medium — Code splitting

- Dynamic import `station-timesheet.tsx` (only needed when timetable opened)
- Dynamic import `station-combobox.tsx` (heavy search component)
- Impact: smaller initial bundle per route

## Files to modify
- `lib/schedule-data.ts` → move to `public/schedule-data.json`
- `lib/schedule-utils.ts` → lazy fetch
- `app/page.tsx` — Suspense fallback
- `app/map/page.tsx` — Suspense fallback
- `app/layout.tsx` — remove Geist fonts, reduce Vazirmatn weight
- `package.json` — remove @base-ui/react
- `lib/layout.ts` — delete
- `components/stations-tab.tsx` — dynamic import timesheet
- `app/home-page.tsx` — dynamic import combobox
