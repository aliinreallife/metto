- `SwaggerUIBundle.preset.standalone` → should be `SwaggerUIBundle.StandalonePreset`

**Fix:** Rewrite `app/api/docs/page.tsx` with correct Swagger UI CDN initialization.

## Issue 2: API rate limiting / Vercel firewall

**Vercel free plan:** Has basic DDoS protection but NO rate limiting or WAF.
**Vercel Pro plan ($20/mo):** Has WAF + rate limiting via Firewall.

**For this app:** Rate limiting isn't critical because:
- The data is static (metro stations don't change)
- The API is read-only
- No authentication needed
- Abuse impact is low (just serve cached data)

**If you want basic protection anyway**, add rate limiting via Edge Middleware:
- Limit: 60 requests/minute per IP on API routes
- This is free (runs on Edge, no extra cost)
