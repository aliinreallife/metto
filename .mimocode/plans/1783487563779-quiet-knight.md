# Fix: Times not updating + loading state + SW cache

## Issue 1: Times don't update after schedule data loads

**Root cause:** `route` memo in `home-page.tsx` depends on `[originId, destId]` — not on `loaded`. When schedule data arrives, the route isn't recalculated with real travel times.

**Fix:**
- `app/home-page.tsx`: Import `useScheduleData`, add `loaded` to route memo deps
- Route recalculates with real timetable data when `loaded` changes

## Issue 2: No loading indicator

**Fix:** Add loading text to components when `loaded` is false:
- `components/route-panel.tsx`: Show "Loading schedule..." when not loaded
- `components/station-card.tsx`: Show loading state for departures
- `components/station-detail.tsx`: Show loading for departures
- `components/station-timesheet.tsx`: Show loading for timetable

## Issue 3: Loading starts on page load (confirmed)

`loadScheduleData()` runs in `providers.tsx` useEffect on mount — starts immediately, not on station selection. This is correct.

## Issue 4: SW caching old invalid JSON

**Fix:**
- `public/sw.js`: Bump `metto-v1` → `metto-v2` to force cache invalidation
- Add `/schedule-data.json` to `APP_SHELL` for pre-caching

## Files to modify
- `app/home-page.tsx` — add `useScheduleData`, add `loaded` to route memo
- `components/route-panel.tsx` — add loading state
- `components/station-card.tsx` — add loading state
- `components/station-detail.tsx` — add loading state
- `components/station-timesheet.tsx` — add loading state
- `public/sw.js` — bump cache version, add schedule-data.json
