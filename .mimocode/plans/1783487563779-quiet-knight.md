# Build MCP Server for Tehran Metro

## Goal
Create an MCP server that exposes metro data as tools for AI assistants (Claude, etc).

## Tools to expose
1. `get_route` — plan route between two stations (by name or coords)
2. `list_stations` — list all stations (filterable by line/search)
3. `get_station` — get single station details
4. `find_nearby` — find nearest stations to GPS coordinates

## Implementation
- Use `@modelcontextprotocol/sdk` package
- Standalone server file: `mcp-server.ts`
- Reuse existing lib functions (`findRoute`, `nearestStations`, `STATION_MAP`, `STATIONS`)
- Run via `npx tsx mcp-server.ts`

## Files
- `mcp-server.ts` — new (standalone MCP server)
- `package.json` — add `@modelcontextprotocol/sdk` dependency
- `public/llms.txt` — add MCP server info

## Verification
1. `npm install` succeeds
2. `npx tsx mcp-server.ts` starts without errors
3. MCP tools are listed correctly
