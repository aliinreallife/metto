# Plan: Hint Users About Place Search

## Goal
Make it discoverable that users can search for place names (parks, landmarks, etc.) in the origin/destination combobox, not just metro stations.

## Approach
Two lightweight hints — no new components needed.

### 1. Update placeholder text (`lib/i18n.ts`)
Change the placeholder from station-only to place-inclusive:
- EN `origin`: `"Origin station"` → `"Station or place name…"`
- EN `destination`: `"Destination station"` → `"Station or place name…"`
- FA `origin`: `"ایستگاه مبدأ"` → `"ایستگاه یا نام مکان…"`
- FA `destination`: `"ایستگاه مقصد"` → `"ایستگاه یا نام مکان…"`

### 2. Add hint in empty dropdown (`components/station-combobox.tsx`)
When the dropdown first opens with no query typed, show a small muted hint below the search input:
- EN: `"You can also search for places like parks or landmarks"`
- FA: `"می‌توانید مکان‌هایی مثل پارک یا بناها را هم جستجو کنید"`

Rendered as a single `<li>` with `text-xs text-muted-foreground text-center py-1.5`. Only shows when `query.length === 0` and `onPlaceSelect` prop is provided.

### 3. Add i18n strings (`lib/i18n.ts`)
- EN `searchHint`: `"You can also search for places like parks or landmarks"`
- FA `searchHint`: `"می‌توانید مکان‌هایی مثل پارک یا بناها را هم جستجو کنید"`

## Files Modified
- `lib/i18n.ts` — 4 placeholder updates + 2 new strings
- `components/station-combobox.tsx` — hint line in empty dropdown

## Verification
1. Open Route tab, tap origin combobox — placeholder reads "Station or place name…"
2. Dropdown opens with no query — hint text visible below search input
3. Type something — hint disappears, station/place results appear
4. Switch to FA — all text is in Farsi
