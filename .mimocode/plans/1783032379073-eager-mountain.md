# Station Card Redesign

## Problems

1. **Double card in Stations tab**: Clicking a station shows a compact row + a full StationCard = 2 cards
2. **Card design not great**: Needs better visual hierarchy and spacing
3. **3 buttons redundant**: From/To/Navigate all serve navigation - user says values are similar
4. **Amenities hidden**: Currently in expandable section, should be always visible
5. **"Open in Maps" unclear**: geo: link opens maps AND taxis (Snapp, Tapsi) but label doesn't convey this

---

## Solution

### 1. Single Card in Stations Tab (no double)

Remove the compact row + expand pattern. Just render StationCard directly in the list. Each station is one card.

```
[StationCard 1]
[StationCard 2]
[StationCard 3]
```

### 2. New Card Design

**Layout:**
```
┌─────────────────────────────────────────┐
│  Station Name              ● 1  ● 2     │
│  Secondary Name                        │
├─────────────────────────────────────────┤
│  [🚻 WC] [🛗 Elevator] [🏧 ATM]       │
├─────────────────────────────────────────┤
│  [📍 Directions]  [🚩 Set as Destination]│
└─────────────────────────────────────────┘
```

Key changes:
- Line badges in header (top right)
- Amenities always visible as compact chips below header
- Only 2 buttons instead of 3:
  - "Directions" (secondary) - opens maps/taxis via geo: link
  - "Set as Destination" (primary) - sets this station as route destination
- No "From" button - user can tap destination, then change origin in route planner

### 3. Button Simplification

**Before**: 3 buttons (Navigate, From, To)
**After**: 2 buttons (Directions, Set as Destination)

Why:
- "From" is rarely used directly - users set destination first, then adjust origin
- "Directions" covers navigation to the station (maps, taxis, walking)
- "Set as Destination" is the primary action

### 4. i18n Changes

```ts
// New strings
directions: "Directions",      // en
directions: "مسیریابی",        // fa

setDestination: "Set as Destination",  // en
setDestination: "تنظیم به‌عنوان مقصد",  // fa
```

Remove:
- `navigate` (replaced by `directions`)
- `from` (no longer a button on cards)

### 5. Files to Modify

1. **`lib/i18n.ts`** - Add `directions`, `setDestination`; remove `navigate`, `from`
2. **`components/station-card.tsx`** - Complete redesign with new layout
3. **`components/stations-tab.tsx`** - Remove expand pattern, render StationCard directly
4. **`components/nearby-tab.tsx`** - Pass `distance` prop, uses same card
5. **`components/station-detail.tsx`** - Update to match new card design

---

## Implementation

### Step 1: Update i18n

Add new strings, remove old ones.

### Step 2: Redesign StationCard

New component structure:
- Header: name + line badges (right-aligned)
- Body: amenities as compact chips (always visible)
- Footer: 2 buttons - Directions (secondary) + Set as Destination (primary)

Remove: `showAmenities` prop, `useState` for amenities expand

### Step 3: Fix StationsTab

Replace the button+StationCard expand pattern with just StationCard:
```tsx
{results.map((s) => (
  <StationCard
    key={s.id}
    station={s}
    lang={lang}
    onSetDest={() => onSetDest(s.id)}
  />
))}
```

No more `openId` state, no more compact row button.

### Step 4: Update NearbyTab

Same StationCard, but with `distance` prop. Remove the numbered circle, keep it simple.

### Step 5: Update station-detail.tsx

Match the new card design (used in map popups).
