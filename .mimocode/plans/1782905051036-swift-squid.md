# Plan: Fix Station Labels — Zoom-Based Visibility

## Goal
- Remove the broken `offset` from tooltips
- Show station labels based on zoom level (like the old SVG map did)
- Prevent label overlap at low zoom

---

## Approach

### 1. Remove `permanent: true` from all tooltips
Instead, manage label visibility dynamically based on zoom.

### 2. Implement zoom-based label visibility
Use the same logic as the old SVG metro-map:
- **Always show**: Route stations, origin, destination
- **Show at zoom >= 12**: Interchange stations (lines.length > 1)
- **Show at zoom >= 14**: All stations

### 3. Implementation in `real-map.tsx`
- Store station markers in a ref (`Map<string, L.CircleMarker>`)
- Listen to `map.on("zoomend")` to update label visibility
- Create a helper `updateLabels()` that shows/hides tooltips based on current zoom
- Call `updateLabels()` on init and on every zoom change

### 4. Fix CSS
- Remove `offset` from the tooltip options
- Keep the `.station-label` styling
