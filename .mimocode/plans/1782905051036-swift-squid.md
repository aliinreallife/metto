# Plan: Match Schematic Background to App Theme

## Goal
The schematic mode's background should match the app's theme colors (`--background` CSS variable) instead of using a hardcoded `#f5f5f5`.

---

## Problem
Currently in `real-map.tsx` line 107: `container.style.backgroundColor = "#f5f5f5"` — this is hardcoded and doesn't adapt to light/dark themes.

## Solution
Read the computed `--background` CSS variable from the document and apply it to the Leaflet container.

### Change in `components/real-map.tsx`

In the `mapMode` effect (line 94-109), replace the hardcoded color with:

```typescript
// Read the app's --background CSS variable
const bgColor = getComputedStyle(document.documentElement).getPropertyValue("--background").trim()
// oklch values need to be wrapped in the function
container.style.backgroundColor = bgColor.startsWith("oklch") ? `color-mix(in srgb, ${bgColor} 100%, transparent)` : bgColor || "#fff"
```

This will:
- Light mode: use `oklch(1 0 0)` → white
- Dark mode: use `oklch(0.145 0 0)` → dark near-black
- Automatically adapt when the theme changes
